## 1. Lua 中的 `and` 和 `or` 简介

在 Lua 中，`and` 和 `or` 是**逻辑运算符**，但它们的用法和行为与其他编程语言（如 C 或 Python）中的逻辑运算符有些不同。它们不仅用于判断真假，还可以直接返回操作数的值，这使得它们在 Lua 中非常灵活，尤其在处理可能为空（`nil`）的数据时。

### **1.1 `and` 的含义**

- **功能**：`and` 检查两个值，如果第一个值为“假”（`false` 或 `nil`），就返回第一个值；否则，返回第二个值。
- **简单理解**：可以看作“如果第一个条件不成立，就停下来；如果成立，就继续看第二个值”。
- **规则**：
  - 如果第一个操作数是 `nil` 或 `false`，返回第一个操作数。
  - 如果第一个操作数不是 `nil` 或 `false`，返回第二个操作数。



### **1.2 `or` 的含义**

- **功能**：`or` 检查两个值，如果第一个值不是“假”（既不是 `nil` 也不是 `false`），就返回第一个值；否则，返回第二个值。
- **简单理解**：可以看作“如果第一个值有效，就用它；如果无效，就用第二个值作为备选”。
- **规则**：
  - 如果第一个操作数不是 `nil` 或 `false`，返回第一个操作数。
  - 如果第一个操作数是 `nil` 或 `false`，返回第二个操作数。
