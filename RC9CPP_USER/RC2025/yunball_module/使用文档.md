# yunball_module 使用文档


### 外部接口函数 ###

## 初始化：
1.  void add_motor(power_motor *turn_motor_); `电机初始化`
2.  void add_io(GPIO_TypeDef *lift_port_, uint16_t lift_pin_,  GPIO_TypeDef *claw_port_, uint16_t claw_pin_, GPIO_TypeDef *push_port_, uint16_t push_pin_); `IO初始化`    `抬升、夹爪、推杆` 

## 控制：
1.    void control_motor(float speed_);   `控制电机转动`
2.    void control_claw(bool claw_state_); `控制夹爪张开、关闭`
3.    void control_push(bool push_state_); `控制推杆开、关`
4.    void control_lift(bool if_up); `控制抬升、落下`

## 自动控制：
1.    void start_yunball(); `自动运球`
2.    void start_putball(); `自动放球`

### 注：
1.  `自动控制函数`被调用时，`手动控制函数`将失效。
2.  `自动控制函数`可以被重复调用，也可以只调用一次。  只有当上一轮自动控制结束时，再次调用该函数才会开启新一轮控制。


## 示例

# setup文件：
```cpp
#include "auto_yunball.h"

auto_yunball yunball_port;

yunball_port.add_motor(&turn_motor);
yunball_port.add_io(GPIOG, GPIO_PIN_6, GPIOG, GPIO_PIN_8, GPIOG, GPIO_PIN_5);   //7发射， 8夹爪，6抬升， 5推射
xbox.add_autoyunball(&yunball_port);

task_core.registerTask(5, &yunball_port);
```


### xbox文件:
```cpp
//控制电机旋转
auto_yunball_ptr->control_motor(xbox_msgs.joyRHori_map);

//抬升、落下
if(down_flag)
{auto_yunball_ptr->control_lift(true);}
else
{auto_yunball_ptr->control_lift(false);}

//夹爪张开、关闭
if(up_flag)
{auto_yunball_ptr->control_claw(true);}
else
{auto_yunball_ptr->control_claw(false);}

//自动运球
if(left_flag){
    auto_yunball_ptr->start_yunball();
    left_flag = 0;
}

//自动放球
if(right_flag){
    auto_yunball_ptr->start_putball();
    right_flag = 0;
}
```
