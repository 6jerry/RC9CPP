# 相机模块使用说明

## 概述

本相机模块用于机器人的目标识别与瞄准系统，主要功能包括：

- 接收相机数据（竖直平面偏差信息）
- 实现 PID 控制的自动瞄准（锁框）功能
- 管理相机工作状态（挂起、启动、完成）
- 与机器人底盘系统集成，实现自动转向

## 文件结构

```
camera.h      # 相机模块头文件
camera.cpp    # 相机模块实现文件
```

## 类说明

### 1. Camera 类

负责接收和处理相机数据

#### 主要功能：

- 接收相机数据（通过 RC9 协议）
- 检查相机状态和错误码
- 存储相机信息（竖直平面偏差）

#### 成员变量：

```cpp
struct {
    Vector2D vertial_plane_deviation; // 竖直平面偏差(像素值)
} camera_info;

bool gaze_flag; // 视野是否丢失标志
```

#### 关键方法：

```cpp
// 构造函数
Camera();

// 数据接收回调函数
void DataReceivedCallback(const uint8_t *byteData,
                         const float *floatData,
                         uint8_t id,
                         uint16_t byteCount) override;

// 检查相机错误状态
err_code check_error() override;
```

#### 错误码处理：

| 状态     | 错误码                | 说明                 |
| -------- | --------------------- | -------------------- |
| 异常数据 | ERR_CODE_ABNORMAL     | 当偏差为(-721,540)时 |
| 连接失败 | ERR_CODE_CONNECT_FAIL | 当偏差为(0,0)时      |
| 正常工作 | ERR_CODE_WORK_SUCCESS | 其他正常情况         |

### 2. CameraOperation 类

负责相机操作和瞄准控制

#### 工作模式：

```cpp
enum CameraMode {
    camera_suspend, // 挂起模式（默认）
    camera_start,   // 启动瞄准
    camera_finish    // 瞄准完成
};
```

#### 成员变量：

```cpp
Camera *camera_ptr;          // 指向Camera对象的指针
bool camera_ready = false;   // 瞄准完成标志
float camera_Y = 0.0f;       // 瞄准完成时的Y值
```

#### 关键方法：

```cpp
// 构造函数（需传入Camera对象指针）
CameraOperation(Camera *camera_ptr_);

// PID锁框控制（计算旋转速度）
float lock_basket_vol();

// 开启相机模式
void camera_on();

// 关闭相机模式
void camera_off();

// 数据处理主函数（需在任务循环中定期调用）
void process_data();
```

#### PID 参数配置：

```cpp
lock_basket_pid.ConfigAll(0.080f, 0.045f, 0.0423f,
                          0.03f, 0.219f, 18.0f, 20.0f);
```

## 使用流程

### 1. 初始化相机系统

```cpp
Camera camera;  // 创建Camera实例
CameraOperation camera_operation(&camera);  // 创建CameraOperation实例
```

### 2. 设置通信端口

```cpp
RC9Protocol ros_port(cdc, nullptr);  // 创建通信端口
camera.addport(&ros_port);  // 将端口添加到Camera
```

### 3. 集成到底盘系统

```cpp
camera_operation.add_chassis(&robot_chassis);  // 添加底盘对象
```

### 4. 在任务管理器中注册

```cpp
TaskManager task_core;
task_core.registerTask(9, &camera_operation);  // 注册相机操作任务
```

### 5. 使用相机功能

```cpp
// 开启相机模式
camera_operation.camera_on();

// 在任务循环中处理数据
camera_operation.process_data();

// 检查瞄准状态
if(camera_operation.camera_ready) {
    // 瞄准已完成，可使用camera_Y值
    float targetY = camera_operation.camera_Y;

    // 执行射击等操作...

    // 重置瞄准标志（需要手动重置）
    camera_operation.camera_ready = false;
}

// 关闭相机模式
camera_operation.camera_off();
```

## 注意事项

1. **瞄准完成标志**：

   - `camera_ready`标志不会自动重置，需要手动重置
   - 在完成射击操作后，应将标志重置为 false

2. **相机模式切换**：

   - 使用 `camera_on()`和 `camera_off()`切换工作模式
   - 在挂起模式(camera_suspend)下，相机不会进行瞄准操作

3. **PID 参数调整**：

   - 根据实际机器人性能调整 PID 参数
   - 可在 CameraOperation 构造函数中修改参数

4. **瞄准阈值**：

   - 当前瞄准完成阈值为 3.0 像素（X 方向偏差）
   - 可在 `lock_basket_vol()`方法中修改阈值

5. **错误处理**：

   - 应定期检查 `camera.check_error()`返回的错误码
   - 根据错误码进行相应的错误处理

## 示例场景（自动瞄准）

```cpp
void auto_aiming_sequence() {
    // 开启相机
    camera_operation.camera_on();

    // 等待瞄准完成
    while(!camera_operation.camera_ready) {
        osDelay(10); // 短暂延时
    }

    // 获取目标距离
    float distance = camera_operation.camera_Y / 1000.0f;

    // 设置射击参数
    auto_shooter_ptr->camera_auto_byFitter(PID, distance);

    // 执行射击
    osDelay(400);

    // 重置瞄准标志
    camera_operation.camera_ready = false;

    // 关闭相机
    camera_operation.camera_off();
}
```

## 调试建议

1. 使用 `lock_basket_debug()`函数输出调试信息：

   - 锁框控制量
   - 相机偏差值

2. 监控 `camera_info.vertial_plane_deviation`值：

   - 正常工作时应有合理的变化范围
   - 持续为 0 或特定值可能表示连接问题

3. 调整 PID 参数时：

   - 先单独测试旋转控制
   - 逐步增加参数值直到系统稳定
