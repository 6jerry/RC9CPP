# Air_Gague 数字气压传感器

**STM32 HAL / C++ 使用手册**

> 通过 UART 读取 **MPa** 级气压数据，支持 **19200 8N1** 协议。

---

## 1. 产品简介

| 项目       | 说明                                                        |
| ---------- | ----------------------------------------------------------- |
| 传感器类型 | 数字气压传感器                                              |
| 量程       | -0.1 ~ 1.1 MPa                           |
| 输出单位   | **整数 kPa**  （看单位转换）           |
| 通信接口   | UART，**19200 波特率，8N1**                           |
| 数据格式   | 8 字节指令 / 5 字节响应（固定帧头）                         |
| 帧头       | 0x12 0x04 0x02                                              |
| 数据位     | 2 字节**Little-Endian**                               |
| 驱动类     | `Air_gague`（继承 `SerialDevice` + `ITaskProcessor`） |

---

## 2. 硬件连接

| MCU 信号 | 传感器引脚 | 说明                  |
| -------- | ---------- | --------------------- |
| TX       | RX         | MCU**发送指令** |
| RX       | TX         | MCU**接收数据** |
| GND      | GND        | 共地                  |
| 3.3 V    | VCC        | 传感器供电            |

## 3. 最小使用示例

### 3.1 创建实例

```cpp
#include "Air_Gague.h"

UART_HandleTypeDef huart2;   // 已在 CubeMX 配置
Air_gague gage(&huart2, UART_BLOCKING);  // 或 UART_IT / UART_DMA
```

### 3.2 周期性读取（RTOS / 裸机通用）

```cpp
air_gague.startUartReceiveIT();
task_core.registerTask(9, &air_gague);
```

实际值可直接获取类内变量air_presure

## 4. 类接口速览

| 成员                                | 功能                                                       |
| ----------------------------------- | ---------------------------------------------------------- |
| `Air_gague(huart, type)`          | 构造函数                                                   |
| `get_air_presure()`               | **发送指令** 并返回最近一次解析后的 **MPa 值** |
| `handleReceiveData(uint8_t byte)` | UART 每收到 1 字节自动调用（中断/DMA 模式需手动转发）      |
| `process_data()`                  | 1. 发送指令 2. 解析完整帧 3. 更新 `air_pressure`         |
| `air_pressure`                    | 最新压强值**MPa**（`float`）                       |
| `air_data.data`                   | 原始**kPa** 整数，可直接做整数运算           |

---

## 5. 数据帧格式

### 5.1 请求帧（固定 8 字节）

```cpp
const uint8_t cmd[8] = {
    0x12, 0x04, 0x00, 0x01, 0x00, 0x01, 0x62, 0xA9
};
```

### 5.2 响应帧（5 字节）

| 字节索引 | 含义                                  |
| -------- | ------------------------------------- |
| 0        | 0x12                                  |
| 1        | 0x04                                  |
| 2        | 0x02                                  |
| 3        | **低 8 位** 气压（kPa） |
| 4        | **高 8 位** 气压（kPa） |

## 8. 校准与扩展

| 需求               | 做法                                                     |
| ------------------ | -------------------------------------------------------- |
| **单位转换** | 直接 `air_pressure / 1000` → MPa                      |
| **滤波**     | 在 `process_data()` 后加滑动平均或 IIR                 |
| **高低报警** | 判断 `air_pressure` 即可                               |
| **掉线检测** | 若 `HAL_GetTick() - lastRxTime > 500 ms` → 传感器离线 |
